# Ngo Hong Tuyen Portfolio

Deploy on Render as a Static Site.

1. Upload this folder to a GitHub repository (render.yaml at repository root).
2. In Render choose New > Static Site and connect that repository.
3. Branch: main. Build Command: echo "Static portfolio ready". Publish Directory: dist.
4. Create Static Site.

Alternatively choose New > Blueprint to use render.yaml.

This portfolio includes the supplied CV, email and phone number. The Render URL serves the portfolio publicly.
